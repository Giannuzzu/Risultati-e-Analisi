# FantAmici – Risultati & Analisi

Webapp statica client-side che legge il foglio `Database` del file Excel.

## Sezioni
- Dashboard: ultima giornata, Analisi Bonus/Malus, classifiche VdM
- Squadre: metriche per reparto, VdM, Top 11 (3-4-3)
- Giocatore: voti utili, utilizzo (grafico ad arco), bonus portati/subentrato/persi e dettaglio giornate
